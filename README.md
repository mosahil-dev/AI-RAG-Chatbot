# 🤖 AI RAG Chatbot

An AI-powered Retrieval-Augmented Generation (RAG) chatbot built using Flask, LangChain, FAISS, HuggingFace Embeddings, and Groq Llama.

## ✨ Features

- 📄 Upload PDF documents
- 💬 Ask questions from uploaded PDFs
- 🤖 AI-generated answers using Groq Llama
- 🔍 Semantic search with FAISS
- 🎤 Voice input
- 🔊 Text-to-Speech output
- 📋 Copy response
- 👍👎 Feedback buttons
- ⏳ Typing animation
- 🌙 Modern responsive UI

## 🛠️ Tech Stack

- Python
- Flask
- LangChain
- FAISS
- HuggingFace Embeddings
- Groq API
- HTML
- CSS
- JavaScript

## 🚀 Installation

```bash
git clone https://github.com/mosahil-dev/AI-RAG-Chatbot.git
cd AI-RAG-Chatbot

pip install -r requirements.txt

python app.py
```

Open:

```
http://127.0.0.1:5000
```
